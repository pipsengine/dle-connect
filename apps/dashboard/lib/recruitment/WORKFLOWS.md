# Recruitment workflows

## Manpower Request
Requester → Department Manager → HR Workforce Validation → Finance/Budget (where applicable) → MD/CEO / authorized final approver.

## Job Requisition
HR Recruitment → Hiring Manager confirmation → HR Manager approval → open for posting.

## Screening
System eligibility checks → recruiter review → shortlist / reject / clarification. AI may assist only against disclosed job criteria.

## Interview
Schedule → candidate confirmation → panel conflict declarations → interview → individual evaluation → consensus recommendation.

## Offer
HR prepares → hiring manager review → Finance/CFO based on compensation threshold → MD/CEO where required → issue → candidate response → version/negotiation history.

## Background Checks
Candidate authorization → verification tasks → result → exception review / waiver if authorized → clear.

## Final Recruitment Approval
All mandatory prior stages passed → HR validates pack → authorized final approval → create/enable onboarding record.
