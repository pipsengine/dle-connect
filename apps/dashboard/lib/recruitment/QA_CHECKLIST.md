# Recruitment QA checklist

- Navigation route exists for each sidebar item.
- Page loads with empty, loading, populated, error and no-permission states.
- Search/filter/sort/pagination behavior.
- Form required fields and validation.
- Duplicate submission protection.
- Workflow transition permission tests.
- No self-approval when segregation is required.
- Candidate consent/retention controls.
- Score override reason captured.
- Interview panel conflict handling.
- Offer version history and locked approved versions.
- Background exception gate.
- Recruitment approval gate to onboarding.
- Audit event for create/update/submit/approve/return/reject/override/export.
- Responsive desktop/tablet/mobile.
- Accessibility labels and keyboard navigation.
