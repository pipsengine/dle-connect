# DLE Connect — Resignation Management Figma Implementation

Two pixel-oriented Next.js/React/TypeScript pages based on the approved reference images:

1. `/hris/offboarding/resignation-management`
2. `/hris/offboarding/resignation-management/new`

## Included
- Full DLE-style shell/sidebar/header
- Six KPI cards and status navigation
- Resignation register with color-coded states
- Selected employee resignation workspace
- Notice calculations, progress and approval workflow
- Complete New Resignation six-step form shell
- Employee/contact/submission/next-of-kin/property acknowledgement sections
- Responsive CSS and reference images for visual QA

## Run
```bash
npm install
npm run dev
```

The values are mock UI data. Replace them with your existing DLE Connect API/services while retaining the CSS classes/layout.
